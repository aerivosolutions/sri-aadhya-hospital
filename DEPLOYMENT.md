# Sri Aadhya Hospital — Deployment

This repository is a standalone static website.

For Cloudflare Pages, connect the repository and use the repository root as the output directory. No build command is required; `index.html` is the production entry point.

The production page no longer depends on the old Emergent preview asset host. The previous generated HTML and broken preview-image placeholders were removed. Hospital photography is intentionally represented by placeholders until the original image files are available.
