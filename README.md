# Sri Aadhya Multi-Speciality Hospital

Production-ready standalone website for Sri Aadhya Multi-Speciality Hospital, Paravada, developed by AERIVO Solutions.

## Deployment

This is a static website. Deploy the repository root with Cloudflare Pages or any static hosting provider. No build command is required.

## Important

The current image URLs temporarily reference the existing preview asset host. Before final client handover, move the hospital images to a permanent production asset location and replace those URLs in `index.html`.

Do not commit secrets or `.env` files.
